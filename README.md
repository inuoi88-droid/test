# TOEIC 4000 フラッシュカード

『TOEIC® L&Rテスト TOEIC® S&Wテスト わかる・使える4000単語』（語研）の見出し語 4010 語を、英日のフラッシュカードで覚えるブラウザのアプリ。スマホ向け。

## 使い方

1. アプリを開き、メールアドレスとパスワードでアカウントを作る（初回だけ。届いた確認メールのリンクを開いてからログイン）
2. ホームの「学習をはじめる」
3. 英単語が出る → 画面をタップすると答え（意味と、よく使う言い回し）
4. **左へスワイプ＝正解、右へスワイプ＝不正解**（下のボタンでも同じ）。どちらでも次の問題へ進む
5. 判定を間違えたら、右上の「1つ前に戻る」

ホーム画面に追加すると、アプリのように開ける（電波がなくても学習でき、あとで自動で同期する）。

PC ではキーボードも使える：Space で答え、← 正解、→ 不正解、Backspace で1つ前に戻る。

## 学習の決まり

- 初めて出た単語に一発で正解 → もう出ない
- 間違えた単語 → その日のうちにもう一度出る（回数には数えない）→ **1日後 → 3日後 → 7日後** に復習（間隔は前の復習から数える）
- 復習で **3回続けて正解** → もう出ない。途中で間違えたら 1日後からやり直し
- 1日の新出の数 ＝ まだ出ていない語数 ÷ 目標日（初期値 12/7）までの残り日数（今日を含む）を切り上げ。休んだ日の分は残りの日に振り分けられる。目標日は設定で変えられる
- 出る順：復習（予定日の古い順）→ 今日間違えた単語 → 新出（本の番号順）
- 1日の区切りは朝4時

決まりは `src/srs.ts`（純粋関数）にまとまっていて、`tests/srs.test.ts` で確かめている。

## しくみ

- Vite + React + TypeScript。`npm run dev` / `npm test` / `npm run build`
- データは Supabase（プロジェクト ability-debate を共用。表と関数は `toeic_` で始まる。定義は `supabase/migrations/`）
  - `toeic_words` 単語（本の通し番号・見出し語・意味・言い回し・GROUP）
  - `toeic_progress` 1人×1単語の学習の記録。端末で答えた時刻が新しい方を残す（`toeic_push`）
  - `toeic_settings` 目標日
  - `toeic_members` 使ってよいメールアドレス。ここに無い人はログインしても単語を読めない
- **単語のデータはこのリポジトリに入れていない**（本の見出し語の一覧なので、ログインした本人だけが読める DB にだけ置く）。意味と言い回しは本の訳ではなく、このアプリ用に書いたもの
- 端末の中の保存は IndexedDB（`src/db.ts`）。答えるたびに保存し、送信待ちに入れて、まとめて送る（`src/store.ts`）。アプリを開いたとき・閉じたとき・電波が戻ったとき・1分ごとに同期
- `public/sw.js` が画面を保存し、オフラインでも開けるようにする
- `?demo` を付けて開くと、ログインなし・見本の12語・同期なしで動く（動作確認用）
